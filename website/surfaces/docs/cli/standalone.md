## Run a project

After installing, open a terminal and check the command:

```console
edi --help
```

Pass the saved project and choose where to write the result:

```console
edi fit path/to/project --output refined-project
```

Use [Run a refinement](fit.md) for the options, or [Run an example](examples.md) to try a complete case.
