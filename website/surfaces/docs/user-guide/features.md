## :fa5-info-circle: How to read this page

**Interfaces** — each cell says whether that interface works with the feature. How a structure or experiment is defined differs between interfaces: see [Defining structures and experiments](#defining-structures-and-experiments). Command line works with every feature a saved project holds.

- :fa5-desktop:{ aria-hidden="true" } Application (browser or desktop)
- :simple-python:{ aria-hidden="true" } Python library
- :fa5-terminal:{ aria-hidden="true" } Command line

<span id="planned-scientific-models"></span>

**Feature status**

- :status-available: Available
- :status-limited: Partial — not fully complete yet; the cell says what is missing
- :status-in-progress: Work in progress — being built now, not available yet
- :status-planned: Planned — a recorded roadmap item, not available yet
- :status-proposed: Proposed — a candidate still under discussion
- :fa5-times-circle: Unavailable
