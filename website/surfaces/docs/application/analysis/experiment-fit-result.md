# <span class="ed-reference-icon" data-reference-category="fit-result-bank" aria-hidden="true">&#61452;</span> Experiment fit result

## Use this group

On **Analysis → Extra**, expand **Experiment fit result**. It separates the recorded results by measurement. This group is read-only. See [Experiment fit result](../../physics/parameters.md#fit-result-bank) in the parameter reference.
