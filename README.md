# edi

edi (EasyDiffraction) is software for diffraction data analysis: it calculates powder diffraction patterns from
structural models and refines their parameters against measured data. It is delivered across four surfaces that share
one API: a Python library (import edi), a command line (python -m edi), a desktop app, and a web app.

## Platforms

The desktop app runs on Linux (x86-64) and on macOS 14 or later (Apple silicon). The web app runs in a current
browser.
