# The assistant desktop candidate

Use the robot button in the app bar to show or hide the Assistant. It slides over the existing manual sidebar, on the same side and within the same bounds. The chart and main workspace keep their size. Hiding it preserves the manual controls, conversation, draft and active work; it does not cancel a fit. The panel starts closed each session. The app-bar button is its only show/hide control.

Choose **Sign in** beside **Clear**, review the readable outgoing-context summary, then continue to OpenAI's sign-in page in your system browser. **Show exact outgoing context** opens the optional technical details; approving the summary covers that same complete context. Use your own ChatGPT account and review the consent there. Messages and selected project metadata go to OpenAI; subscription availability and usage limits depend on your account. This candidate uses subscription access and does not ask for an API key. Windows sign-in is not available yet.

Before sign-in and model discovery, the selector shows **Effort**. After connecting, choose an available model and reasoning effort; it shows the selected name. **Auto** lets the model or provider choose the reasoning effort. The candidate remembers your last model/effort pair in Edi's application settings and restores it only when the provider's current catalog supports it. Sign-out, Clear and a temporary empty catalog do not replace that preference with an automatic fallback. An unavailable saved choice uses a visible fallback; inspect it before sending.

Use **+** to select local files. Actual selected names and byte counts appear above the draft; each item has a remove control. Native file drops onto the chat area use the same bounded intake. Desktop chooser backend and multiple-selection gestures are still being qualified; adding files through repeated chooser selections and grouped native file drops are distinct routes. Folder intake and browser file transfer remain unfinished. Typing a file or folder path does not grant access. Selection alone does not import data, create a project or run a fit.

Outgoing consent includes the selected-file manifest and permission for bounded text reads. It does not upload every file as an attachment or dump all bytes into a request. Binary or unsupported formats need a supported text export; selected content is data, not instructions. Live provider use of these inputs still needs verification.

Ask about the project and inspect any proposed plan. Approval covers its displayed parameter groups and trial budget. Stop cancels the active assistant work; manual changes invalidate an old approval. Trials use a separate project copy, and an unverified or worse result is not automatically adopted. Existing manual fitting remains available. Sending a follow-up while work is active is not implemented yet; the current busy guard remains in force.

The small chevrons beside Send/Stop inside the composer browse previous or next user messages. The larger monochrome action is Send or Stop. Conversation overflow uses the same noninteractive scroll indicator as the manual sidebar; scroll the conversation normally. The neutral usage ring opens details, but this connection does not currently supply context-window or subscription-limit metrics. No percentage is inferred from conversation length or elapsed time.

Conversation activity is saved separately from the project on this computer. **Clear** retires the assistant conversation and selected inputs, removes its archive and starts fresh; it does not clear the scientific project or sign you out. Sign out removes the selected saved connection. The displayed archive is not automatically sent in a new app session.

This is an implementation candidate, not a verified live-subscription release. Successful live chat, streamed inspection and an approved mutation still need verification. Decoder failure details preserve the available bounded reason and original category; diagnostics alone do not fix the failed request. Native Claude, the computer-browser connector, folder/browser file intake, complete sequential optimization and FullProf/GSAS-II import remain unfinished. A screenshot labelled SAMPLE shows original local preview text, not a live provider exchange or a completed refinement.
