# <span class="ed-reference-icon" data-reference-category="data-range" aria-hidden="true">&#62263;</span> Calculation range

## Use this group

On **Experiment → Main**, expand **Calculation range**. For an experiment without measured data, it sets the grid the pattern is calculated on. After you load data, the measured points define the range instead. See [Calculation range](../../physics/parameters.md#data-range) in the parameter reference.
