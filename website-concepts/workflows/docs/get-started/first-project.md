# Your first project

<p class="ed-doc-lead">Start with measured data and a complete model, then follow the analysis from the structure to its fit.</p>

## Open the LBCO example

The catalogue project `pd-neut-cwl_lbco-hrpt` describes La₀.₅Ba₀.₅CoO₃ measured on HRPT. In the app, find it in Examples. In a configured repository checkout, its project folder is `docs/user/cli/pd-neut-cwl_lbco-hrpt/project`.

## Inspect the structure

Look at the cell and atom sites. La and Ba share a site; their occupancies describe the model's chemical composition. Open the [structure guide](../guides/structure.md) if these ideas are new.

## Compare the patterns

Find the measured points, calculated curve, residual and Bragg positions. Change one parameter and see which part of the pattern responds.

## Refine and inspect

Choose the parameters to vary and run the fit. Then inspect the residual and uncertainties, as well as the agreement factors. A smaller agreement factor alone is not a complete interpretation.

[Refine a model →](../guides/refine.md)
