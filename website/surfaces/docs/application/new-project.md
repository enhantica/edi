# :material-archive: Create a project

## Enter the project details

On **Home**, press **Start**, then choose **Create a new project** on **Project → Main**. Enter a short name, a descriptive title, authors and a description. Choose a location and confirm.

The project name identifies its folder; the title appears in the report. If another project has unsaved changes, answer the save prompt before replacing it.

## Choose uncertainty formatting

On **Project → Extra**, expand **Standard uncertainties**. Choose the display rule used for values and their standard uncertainties. This setting is saved with the project.

The formatting changes how a result is written, not the fitted value or its uncertainty. See [uncertainty conventions](../physics/minimization.md).
