# Web application

Open EasyDiffraction in a browser, with no application installation.

[Open the web app](https://enhantica.github.io/edi/webapp/){ .md-button .md-button--primary }

The [application layout](workspace.md) and controls are identical in the browser and on the desktop. File access and saving depend on your browser.

## Open and save files

**Open project…** accepts a folder or zip archive. When importing a structure or measured pattern, select the file in your browser's file chooser.

Choose your browser:

=== ":fontawesome-brands-chrome: Chrome"

    Opening a local folder or archive can retain access to that location. **Save** writes back there; **Save project as…** chooses a new location.

=== ":fontawesome-brands-edge: Edge"

    Opening a local folder or archive can retain access to that location. **Save** writes back there; **Save project as…** chooses a new location.

=== ":fontawesome-brands-firefox-browser: Firefox"

    Projects are kept in browser storage. **Save project as…** downloads a zip copy.

=== ":fontawesome-brands-safari: Safari"

    Projects are kept in browser storage. **Save project as…** downloads a zip copy.

!!! note "Check where your project is saved"

    New projects and built-in examples initially use browser storage in every browser. When the location reads **In this browser only**, use **Save project as…** to keep a copy outside the browser or move it to another computer.


## Return to your work

Use **Recent projects** or **Continue where you left off** after reloading or reopening the app.

!!! warning "Keep a copy before clearing browser data"

    Clearing the browser's site data removes browser-held projects. Private browsing may remove them when the session ends. Download the projects you want to keep first.

## Export reports

Saving a report downloads the selected files. For direct access to project folders and report files, use the [desktop application](desktop.md).
