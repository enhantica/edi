# Interpret a fit

<p class="ed-doc-lead">Use the full pattern and the model together. An agreement factor is one part of the evidence.</p>

## Inspect the residual

Look for differences that follow peaks, the background or a particular range. Structured residuals can reveal a model or measurement effect that a single summary value hides.

## Read agreement factors

Rₚ describes an unweighted difference. Rwp uses the observation weights, and reduced χ² also depends on the observations and number of free parameters. Compare values only when the data, weighting and fitted range are understood.

## Inspect uncertainties and correlations

Read the uncertainty alongside a refined value. Correlated parameters may be difficult to determine separately from this dataset; more free parameters do not automatically give more information.

## Compare with a reference

The example catalogue provides reproducible projects. Where a comparison with FullProf or diffraction-lib exists, preserve the same model, data, exclusions and free parameters when assessing the difference.
