# The assistant desktop candidate

Open the Assistant from the app bar or press Ctrl+Shift+A (Command+Shift+A on macOS). It appears opposite the workflow sidebar; drag its edge to resize, or hide it to use the full chart. Preferences remembers its width and visibility.

Choose Connect ChatGPT to open OpenAI's sign-in page in your system browser. Use your own ChatGPT account and review the consent there. Messages and selected project metadata go to OpenAI; subscription availability and usage limits depend on your account. This candidate uses subscription access and does not ask for an API key. Windows sign-in is not available yet.

After connecting, choose a model returned by the provider, ask about the open project and inspect the proposed plan. Approval covers the displayed parameter groups and trial budget. Stop cancels the active assistant work. Manual changes invalidate the old approval. Trials use a separate project copy; an unverified or worse result is not automatically adopted. Existing manual fitting remains available.

Conversation activity is saved separately from your project on this computer. The clear-conversation button removes that archive and starts a fresh assistant conversation while idle. Sign out removes the selected saved connection. The displayed archive is not automatically sent in a new app session.

This is an implementation candidate, not a verified live-subscription release. An actual account sign-in, streamed inspection and approved mutation still need verification. Native Claude, browser access, attachments, complete sequential optimization and FullProf/GSAS-II import are not supplied by this first desktop slice.
