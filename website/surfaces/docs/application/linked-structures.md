# <span class="ed-reference-icon" data-reference-category="linked-structure" aria-hidden="true">&#62973;</span> Linked structures

## Choose the contributing phases

On **Experiment → Main**, expand **Linked structures**. Use **Add linked structure** to select a structure already present in the project. Inspect each link's scale and derived weight fraction.

Disable a link to keep it in the project without contributing to calculation or fitting. Remove it to unlink the structure from this experiment; the structure itself remains in the project.

For several phases, refine their scales deliberately. Weight fractions are calculated from the model and scales rather than entered independently. See [scale and phase fractions](../physics/diffraction.md#phase-fractions).
