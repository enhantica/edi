# <span class="ed-reference-icon" data-reference-category="extinction" aria-hidden="true">&#62373;</span> Extinction

## Use this group

On **Experiment → Main**, expand **Extinction**. For a single-crystal experiment, it sets the extinction correction: its type, mosaic distribution and parameters. See [extinction](../../physics/corrections/extinction.md) for the models. See [Extinction](../../physics/parameters.md#extinction) in the parameter reference.
