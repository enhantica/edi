# Security

Please report a security problem privately, with **Report a vulnerability** on the repository's
[Security tab](https://github.com/enhantica/edi/security), rather than in public feedback or a pull
request. Say what you found, how to reproduce it and which version you used (shown under **About**).

We reply as soon as we can and publish a fixed release before the details are made public. Only the
latest release is supported; please update before reporting.
