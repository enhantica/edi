## Use this group

On **Experiment → Extra**, expand **Fitted reflections**. For a single-crystal experiment, it sets which reflections a fit uses. The same group is on [Analysis → Extra](../analysis/fitted-reflections.md). See [Fitted reflections](../../physics/parameters.md#refine-ls) in the parameter reference.
