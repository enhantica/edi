# Application

<p class="ed-doc-lead">A visual workspace for the project, its model, measured patterns and fit.</p>

## The pages

| Page | Purpose |
| --- | --- |
| Project | Create, open and manage the project. |
| Structure | Inspect the crystal structure, cell and atom sites. |
| Experiment | Describe the measurement, profile, background and linked structures. |
| Analysis | Choose parameters, fit and inspect results. |
| Report | Review and export the analysis. |

## Desktop and browser

The interfaces share their scientific model and visual workflow. Desktop file dialogs work with local files and folders; the web application uses the browser's chooser, storage and downloads.
