# <span class="ed-reference-icon" data-reference-category="sequential-fit-extract" aria-hidden="true">&#61616;</span> Scan extraction rules

## Use this group

On **Analysis → Extra**, expand **Scan extraction rules**. For a scan, it shows the rules used to extract values such as temperature from the measurement files. See [Scan extraction rules](../../physics/parameters.md#sequential-fit-extract) in the parameter reference.
