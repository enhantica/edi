# <span class="ed-reference-icon" data-reference-category="refine-ls" aria-hidden="true">&#61636;</span> Fitted reflections

## Use this group

On **Analysis → Extra**, expand **Fitted reflections**. For a single-crystal experiment, it sets which reflections a fit uses. See [Fitted reflections](../../physics/parameters.md#refine-ls) in the parameter reference.
