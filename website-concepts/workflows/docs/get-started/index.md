# Your first diffraction project

<p class="ed-doc-lead">Choose how you want to work. The structure, experiment and analysis belong to the same project in every interface.</p>

## Start in the browser

The quickest way to explore edi is to [open the web application](https://enhantica.github.io/edi/webapp/) and choose an example. You can inspect a structure, compare measured and calculated patterns, and explore the parameters without installing the desktop application.

## Choose your workspace

| Workspace | A good place to start when… | Next step |
| --- | --- | --- |
| Application | You want to see your data and model together. | [Browser](web.md) or [desktop](desktop.md) |
| Python | You want a script or notebook you can revisit. | [Python and CLI setup](python-cli.md) |
| Command line | You have a project and want a repeatable run. | [Command-line reference](../reference/cli.md) |

## Follow one example

Use a complete project from the example catalogue before bringing your own data. The same example is available to the app, Python and command line, so you can compare the workflows directly.

[Open your first project →](first-project.md)

## Learn the shared model

A **structure** describes the crystal. An **experiment** describes the measurement and the pattern model. **Analysis** brings them together for calculation or refinement. [The guides](../guides/index.md) follow that sequence and explain interface differences where you need them.
