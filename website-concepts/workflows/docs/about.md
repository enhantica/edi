# About EasyDiffraction

<p class="ed-doc-lead">Making diffraction data analysis and modelling easy.</p>

## One product, several ways to work

EasyDiffraction brings the visual application, Python library and command-line interface together around edi's shared project model. The crysta engine supplies diffraction calculation and refinement underneath that model.

## Open scientific software

The [edi source](https://github.com/enhantica/edi) is openly available. Its source is licensed under BSD-3-Clause; the built application follows GPL-3.0 because of the Qt components it links.

## This design concept

This preview brings the former landing page, application documentation and Python documentation into one user-focused website. It demonstrates the proposed information architecture using current edi examples. It is not a complete documentation migration or a new product release.

## Contribute

[Report an issue or suggest an improvement](https://github.com/enhantica/edi/issues). Contributor and architecture material remains reachable from the footer, separate from the main user navigation.
