# <span class="ed-reference-icon" data-reference-category="sequential-fit" aria-hidden="true">&#61643;</span> Sequential fit

## Use this group

On **Analysis → Extra**, expand **Sequential fit**. For a scan, it shows the saved declaration: the data directory, file pattern and order. [Work with a scan](../scans.md) follows a complete run. See [Sequential fit](../../physics/parameters.md#sequential-fit) in the parameter reference.
