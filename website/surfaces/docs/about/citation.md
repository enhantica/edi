# How to cite

If you use EasyDiffraction in your work, please cite it. The app shows the same citation under Home → How to cite.

## Citation

Andrew Sazonov, Eric Lindgren, Piotr Rozyczko, Mridul Seth (2026). EasyDiffraction (version 0.21.1) [Computer software].
DOI: [10.5281/zenodo.22905049](https://doi.org/10.5281/zenodo.22905049)

```bibtex
@software{easydiffraction,
  author = {Andrew Sazonov and Eric Lindgren and Piotr Rozyczko and Mridul Seth},
  title = {EasyDiffraction},
  year = {2026},
  version = {0.21.1},
  doi = {10.5281/zenodo.22905049},
  url = {https://doi.org/10.5281/zenodo.22905049}
}
```

Also say which version of EasyDiffraction you used. The app shows it in its About window, and in Python
`edi.__version__` holds it.

## Keep your analysis repeatable

Save the project with your result. It holds the data, the structural model and every setting, so you or someone else can open it and continue. A [report](../application/report/index.md) gives a readable summary of the model and the fit; keep it alongside the project.

Also cite the sources of your data and structural models.
