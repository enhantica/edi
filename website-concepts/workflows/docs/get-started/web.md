# Use the web application

<p class="ed-doc-lead">Explore a complete project in your browser, without installing the desktop application.</p>

## Open an example

[Launch the web app](https://enhantica.github.io/edi/webapp/). On the Project page, choose an example from the catalogue. Begin with one measured powder pattern so you can follow the structure, experiment and calculated curve together.

## Work through the pages

The app's sequence is **Project → Structure → Experiment → Analysis → Report**. The [shared guides](../guides/index.md) explain the decisions in that workflow.

## Browser files

The browser opens files through its file chooser. Saving exports a download; it does not give the application unrestricted access to folders on your computer. Keep a downloaded copy of work you want to retain.

## Continue on the desktop

The desktop and browser application share the project model. [Desktop application](desktop.md) explains what changes when you work with local files and folders.
