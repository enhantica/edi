# Choose your interface

Use the application for direct visual exploration, Python when your analysis belongs in a script or notebook, and the CLI when you want to run a saved project from a terminal.

## Application

[Desktop and browser](../application/index.md) share the visual workspace. The browser is the easiest place to try an example; the desktop works directly with your local files.

## Python

[The Python library](../python/index.md) exposes the project model as `edi`. Load a complete project, run its analysis and inspect the result from your code.

## Command line

[The CLI](../cli/index.md) takes a project directory. Its analysis settings stay in the project, making the saved input the record of what you asked to run.

## Shared concepts

Structures, experiments and fitting modes belong to the same [project model](../learn/projects.md) across all three interfaces.
