## Use this group

On **Structure → Extra**, expand **Atoms in the cell**. It lists every atom of the unit cell, generated from the atom sites by symmetry. This group is read-only. See [Atoms in the cell](../../physics/parameters.md#expanded-atom-site) in the parameter reference.
