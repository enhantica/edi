# ADR-0004: Interface entry pages and installation routes

Date: 2026-10-30
Status: implementing

## Prior art

The Application, Python and Command Line entry pages repeated the shared scientific workflow and example guidance. Browser and desktop pages also mixed interface differences with those generic instructions. ADR-0001 already supplies themed screenshot enlargement; the homepage already has the approved application hero.

## Decision

Each interface entry page presents its interaction style, a real representative screenshot, installation or launch actions, and links to the interface's instructions. Scientific capabilities and the shared workflow stay in the User guide and Physics. The application preview reuses the homepage image; Python shows a running notebook and Command Line a terminal session.

Desktop downloads have one canonical home at `application/desktop/#download`. The homepage's Desktop app shortcut links directly there, providing one-click access without duplicating download controls on Application. The application entry links to the same section. Browser and desktop pages focus on their file handling and installation differences.

Command Line has separate standalone and Python-package setup pages. Usage examples offer matching invocation tabs (`edi` and `python -m edi`) with identical arguments. Neither requires Python scripting. Standalone availability is stated on its installation page until executable releases exist. Package install instructions follow actual package availability rather than linking a similarly named package or an older product release.

`distributions.json` is the source for platform download URLs. A missing URL renders a disabled control, never a fabricated link or a link to an older application. Download-page markers and interface-preview markers are generated by the shared renderer; screenshot titles remain accessible without repeated captions.

## Validation

Build checks verify generated links and assets. Browser checks cover the interface entry pages, preview enlargement, one-click download anchor, disabled pending controls, invocation tab parity, and responsive layouts. Capture sources and commands are retained with the screenshot assets.

The Command Line entry explicitly compares standalone executable (no Python installation) with Python package (Python environment), including each invocation. Both use shell commands without Python scripting. Use tabs for differing command syntax; keep the shared Application preview with web/desktop entry links and explain file-access differences on the dedicated pages.

2026-10-31 clarification: browser-specific saving instructions use native icon-labelled Chrome, Edge, Firefox and Safari tabs instead of a comparison table. Keep the shared browser-storage note and data-loss warning outside those tabs and visible for every selection.
