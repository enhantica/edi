# Projects and files

A project keeps the model and the analysis together: structures, experiments, measured data, fitting settings and results.

## Open and save

Open a saved project on the **Project** page. Save after changing parameters or refining if you want to keep those changes.

## Desktop and browser

The desktop works with local folders. The browser uses uploads and downloads, so keep the downloaded project when you finish a session.

## Move between interfaces

Use the saved project from the [Python library](../python/fit.md) or [CLI](../cli/fit.md). The [shared project model](../learn/projects.md) explains its contents.

## Reports are separate

Saving a project preserves your working state. [Saving a report](reports.md) creates a document for sharing the result.
