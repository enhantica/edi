# Projects and experiments

A project is the unit you open, analyse and save. It connects the structural model to the experiments and records how the analysis should run.

## Structures

A structure describes its space group, unit cell and atom sites. Several structures can contribute to the same experiment.

## Experiments

An experiment describes the measurement or simulation: instrument, peak profile, background, range or measured data, and links to structures.

## Analysis

The project declares the parameters that vary and the fitting mode. A single fit, a joint fit and a scan use the same structures and experiments with different analysis settings.

## Results and reports

Save the project to preserve its values and settings. Save a report when you want a separate document to inspect or share.
