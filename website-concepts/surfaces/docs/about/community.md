# Get involved

EasyDiffraction is shaped by the people who use it for scientific work.

## Ask or report

Use the [edi issue tracker](https://github.com/enhantica/edi/issues) to report a problem or suggest an improvement. Include the project or a small example, what you expected, and what happened.

## Contribute

For architecture, development setup and testing, use the separate [contributor documentation](https://enhantica.github.io/edi/dev/).

## Cite the software

Use the citation associated with the release you used, and include its version with your analysis. Keep the project inputs so that the calculation can be reproduced.
