# <span class="ed-reference-icon" data-reference-category="fit-result" aria-hidden="true">&#61528;</span> Fit result

## Use this group

On **Analysis → Extra**, expand **Fit result**. It holds the overall outcome and statistics of the last fit. This group is read-only. See [Fit result](../../physics/parameters.md#fit-result) in the parameter reference.
