# A powder refinement

<p class="ed-doc-lead">Explore La₀.₅Ba₀.₅CoO₃ measured on HRPT, from the initial project to the refined pattern.</p>

## Open the example

Find `pd-neut-cwl_lbco-hrpt` in the app's Examples. Python and the command line can open the catalogue's same project folder in a configured repository checkout.

## Inspect its model

The cubic structure has La and Ba sharing one site. Look at its cell, occupancies and displacement parameters, then inspect the instrument, peak profile and background on the Experiment page.

## Calculate and refine

Compare the starting calculation with the measured pattern before fitting. Follow [refine a model](../guides/refine.md) for the application, Python and CLI steps.

## Review the outcome

Inspect the residual, parameter values and uncertainties. Save the refined project to a new location and prepare a report. The [existing complete example](https://enhantica.github.io/edi/user/cli/pd-neut-cwl_lbco-hrpt/) supplies the reference project and comparison details.
