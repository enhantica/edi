## Report a problem

It helps to tell us:

- what you did, what happened and what you expected;
- whether you use the browser app, the desktop app, Python or the command line, and its version;
- a small project or file that shows the problem, if you can share it.

Leave out unpublished or confidential data.

## Other ways

You can also open an issue on [GitHub](https://github.com/enhantica/edi/issues). If you would like to work on the code, start with the [contributor documentation](https://enhantica.github.io/edi/dev/).
