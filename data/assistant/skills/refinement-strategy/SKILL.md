# Adaptive refinement of an actual Edi project

Version: 1.4.9. This is scientific guidance for actually offered operations. The agent chooses the steps and stopping point from evidence and the user's goal; no finite staged recipe or pass count is mandatory.

Inspect the measured shape, units, weighting, exclusions, structure, calibration, current fit variables, constraints and diagnostics. Preserve input provenance and compare like objectives on comparable observations. A lower residual or a saved project alone does not establish a physically meaningful model. Distinguish an unavailable action, an unidentifiable variable and an observed scientific defect.

Import a supplied CIF by default unless manual entry is requested. Use the ordinary native Estimate with current saved settings for initial background work, unless the user supplies explicit manual anchors. Inspect its current type, estimation mode, anchors/terms and native eligibility before subsequent refinement. An initial Estimate does not establish that baseline bias is resolved. Do not impose manual anchors, change ownership or free all background values as a universal first stage.

Choose identifiable variable groups from actual geometry and intensity evidence; coordinate and displacement work may need separate trials followed by joint reassessment. Request a whole eligible group together using exact current paths and the ordinary category selector/Free header when its shown eligible members match; do not replace that group action with avoidable individual-checkbox calls. With a credible model, cumulative release may be useful; divergence or actually observed correlations may justify a smaller temporary group and renewed diagnosis. Large uncertainty alone is not a measured correlation; report unexposed correlations as unknown. Alternative starts or model families require actual supported operations and a restorable state. Ordinary fit Undo is a single current opportunity, not a checkpoint bank. Respect actual native fittability and preserve explicit calibration anchors, chemical composition, symmetry constraints and requested flags.

For powder data, establish measured/calculated peak-position and width/shape evidence before attributing an intensity mismatch to occupancies or ADPs. Read actual measured/calculated/residual slices with inspect_data and separate Bragg rows unless this evidence is already established; inspect their units, availability and current/adopted state. Structural refinement includes justified instrument, position, profile and background work, not only Structure-tab variables. Native defaults and setup values, including zero, are starts unless the user or input establishes calibration anchors. When measured/calculated peak positions mismatch, first resolve alignment using the eligible cell/offset/scale variables from actual app defaults, with the supplied wavelength anchored, before releasing width or displacement variables to absorb the position error. For a new constant-wavelength powder task with a credible imported model, try that eligible joint group before proposing another starting offset. A genuinely stalled or rejected trial can motivate a data-supported alternative start; record that evidence rather than seed specimen/tutorial/online fitted constants. Do not reset an already accepted fit or genuinely supplied nonzero calibration. Preserve genuinely known wavelength/calibration, composition and symmetry; broadening a displaced calculated pattern is not an alignment correction.

Assess each trial before another fit: inspect adoption, actual parameter changes, existing physical diagnostics and current residual/profile behavior over the measured range. Stabilize observed baseline bias before interpreting ADPs. For diagnosis, compare restorable candidates that change the implicated factor, rather than changing profile family and unrelated background/structural variables together. Check the CURRENT engine convention and physical widths across measured reflections: the native CW Lorentzian width is X tan(theta) + Y/cos(theta), with theta the Bragg angle. X/Y are not universally exclusive, and signed empirical coefficients alone do not establish an invalid physical profile. If an adopted candidate is scientifically unacceptable and its native fit Undo is available, restore it before another fit consumes that opportunity, then inspect the restored state. A refused or unadopted trial does not authorize undoing earlier accepted science. Changing a free flag does not repair its current value: freezing an unacceptable value retains that model defect. Resolve or honestly report unresolved physical problems before treating a candidate as accepted; never claim an unavailable check.

After structural or displacement changes, reassess an earlier unstable but identifiable group when the actual residual still warrants it. Its earlier failure may no longer describe the current model. Before finishing, revisit temporary freezes or isolation choices against the accepted geometry and residual; undoing a rejected displacement trial does not by itself restore an earlier temporary flag choice. Neither solver convergence, no_step nor one failed displacement trial establishes completeness while the actual residual still warrants identifiable alignment, profile or background work. Check actual residuals and current calculation availability; a stored fit statistic is not evidence for a later edited or saved model. A large reduced chi-square can warrant data, uncertainty or model diagnosis, not forcing the statistic toward one. Continue useful scientifically justified work from the accepted state.

For single-crystal data, inspect actual F-squared residuals and their intensity dependence when assessing scientifically appropriate extinction and displacement variables. Use the current native extinction family, mosaic-distribution options and exposed parameters; obey fittable/fit_reason rather than blindly applying a powder cell/wavelength release group to inactive SC fields. Enter a supplied crystal size/radius in the native field and units as requested, without inventing a diameter conversion. Model and variable choices follow evidence, not a reference screenshot. Zero local sensitivity can depend on the selected model and its other values; do not assume a zero-start stall is limited to the mixed Becker–Coppens family. Only after observing actual stall/sensitivity evidence may a supported variable receive a small positive, physically justified trial start. Explain its scale, inspect the response and uncertainty, and retain a restorable state. A zero value alone does not justify changing it; never seed fitted values from another experiment.

For mixed sites, establish the intended same-phase co-occupancy model before imposing relationships; shared coordinates require that actual model and scope. Separately, distinct sites of the same atom type in similar bonding environments can justify a restorable shared-isotropic ADP trial when weak identifiability or correlations support simplification. Co-location is not required, and the same element alone is insufficient. When the data cannot identify site-specific isotropic ADPs, evaluate a physically justified shared/broader group or one overall isotropic ADP as a simpler candidate; explain the actual choice or unavailable comparison and the lost site-specific information. One failed independent-ADP trial does not settle these alternatives. Negative ADPs alone do not justify global sharing or automatically replacing an established anisotropic model. Keep the physical convention and units consistent: Biso and Uiso are not literal-equal without conversion. Native symmetry relationships are distinct from modelling constraints between independent sites. Keep coordinates and occupancies independent in these trials; compare residuals, uncertainties and model complexity, and state the imposed approximation. Do not impose arbitrary equality on full anisotropic tensors, especially across different frames. Use only supported native relations: affine constraints are not general geometric restraints. Do not apply an X-ray atom-order heuristic as a universal neutron rule. Report unresolved correlations and conditional uncertainties honestly.

When existing guidance or a supported route fails, use hosted public search/read to discover alternatives. Relevant sources include Edi documentation and public source, engine/API documentation and scientific primary literature. Keep queries to public concepts; do not send raw experimental data, unpublished sample descriptions, credentials or private paths. Retain actual URLs/citations and explain which decisions are inferred from them. Research can identify a missing capability without pretending that Edi executed it.

Use actual current inspection, diagnostics, setters, relations and fit operations. Wait for settled native calculation before a fit. Interpret termination and adopted values literally, inspect changes and physical validity, and continue only justified work. Never replay partial or uncertain effects, bypass a native owner rule, change the action mode or silently replace scientific inputs to obtain a smaller objective. Ask only for genuinely missing information or an indispensable user action.

At the endpoint, inspect the authoritative current parameter values and uncertainties, save through the ordinary Session route when requested/delegated, and distinguish observed results from assumptions. Automatic project reports retain settled/final history and research attribution; their failure cannot prevent scientific work. Include useful final recommendations for skill, tool or app improvements exposed by the task, without requiring /work-report.

Useful starting references for discovery, to read where relevant:

- McCusker et al., Rietveld refinement guidelines: https://journals.iucr.org/j/issues/1999/01/00/gl0561/
- Toby, International Tables for Crystallography H, Rietveld refinement (2019), model simplification and isotropic displacement grouping: https://onlinelibrary.wiley.com/iucr/itc/Ha/ch4o7v0001/
- Young (ed.), The Rietveld Method: https://doi.org/10.1093/oso/9780198555773.001.0001

References inform a strategy; they do not replace the actual user's data, native model or explicit scope.
