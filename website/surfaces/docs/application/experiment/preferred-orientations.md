## Set preferred orientation

On **Experiment → Extra**, expand **Preferred orientations**. Choose **Add preferred orientation**, identify the linked structure and preferred hkl direction, then set the March parameter and random fraction. Remove a row to remove that correction.

Use a correction supported by the sample preparation and diffraction evidence. See [preferred orientation](../../physics/corrections/orientation.md) for the parameter meanings.
