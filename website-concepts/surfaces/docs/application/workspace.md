# Find your way around

The app follows the shape of a diffraction analysis. Move between the pages at the top; each page keeps the relevant controls beside the working view.

## Project

Open an existing project, choose an example, or start a new project. A project holds your structures and experiments together with analysis settings and saved results.

## Structure

Inspect the space group, unit cell and atom sites. A project can contain several structures, each linked to the experiments it contributes to.

## Experiment

Compare the measured pattern with the calculated pattern. Adjust the instrument, peak profile, background and excluded regions in the sidebar.

![Experiment controls and a calculated pattern](../assets/edi-app.png)

## Analysis

Choose the parameters that vary and run the project's fit. Review the residual, agreement factors and uncertainties together.

## Report

Review the structures, experiments and fit as a document. [Reports](reports.md) can be saved for sharing independently of the project.

## Messages and undo

Messages in the status bar explain what happened when data were loaded or an operation was refused. Undo lets you step back through changes to the project.
