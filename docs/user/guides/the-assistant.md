# The assistant desktop candidate

Open the Assistant from the app bar or press Ctrl+Shift+A (Command+Shift+A on macOS). It appears opposite the workflow sidebar; drag its edge to resize, or hide it to use the full chart. Preferences remembers its width and visibility.

Choose **Sign in with ChatGPT**, review the readable outgoing-context summary, then continue to OpenAI's sign-in page in your system browser. **Show exact outgoing context** opens the optional technical details; approving the summary covers that same complete context. Use your own ChatGPT account and review the consent there. Messages and selected project metadata go to OpenAI; subscription availability and usage limits depend on your account. This candidate uses subscription access and does not ask for an API key. Windows sign-in is not available yet.

After connecting, choose a model returned by the provider, ask about the open project and inspect the proposed plan. Approval covers the displayed parameter groups and trial budget. Stop cancels the active assistant work. Manual changes invalidate the old approval. Trials use a separate project copy; an unverified or worse result is not automatically adopted. Existing manual fitting remains available.

Conversation activity is saved separately from your project on this computer. The clear-conversation button explicitly retires the assistant conversation, removes its archive and starts fresh; it does not clear the scientific project. Sign out removes the selected saved connection. The displayed archive is not automatically sent in a new app session.

This is an implementation candidate, not a verified live-subscription release. Successful live chat, streamed inspection and an approved mutation still need verification. If Edi cannot decode a response, its failure details show the available bounded decoder reason and original error category; this diagnostic does not itself establish the cause or fix the failed request. Typing a local file or folder path does not grant access or attach its contents. Use existing manual project/data workflows for now. Native Claude, browser access, file chooser/drop attachments, complete sequential optimization and FullProf/GSAS-II import remain unfinished.
