# About EasyDiffraction

EasyDiffraction makes diffraction modelling and refinement available through a visual application, Python and the command line. Calculate a signal from a structural model, compare it with observations, refine selected parameters and retain the analysis as a project.

## One product, connected interfaces

The browser and desktop applications provide a visual workspace. Python supports scripts and notebooks using `edi`. The command line runs saved projects with `python -m edi`.

The interfaces share the project model and native calculation core, using crysta for diffraction calculation and minimisation. A complete project keeps structures, experiments, analysis settings and results connected as you move between interfaces.

## Open scientific software

The source is available in the [edi repository](https://github.com/enhantica/edi). The source code is licensed under BSD 3-Clause, and the built graphical application is distributed under GPL version 3. See [licensing](licence.md) for the authoritative files and notices.

The repository also contains examples and their scientific provenance. Keep the model, data and software version with your results so another person can inspect and repeat the analysis.
