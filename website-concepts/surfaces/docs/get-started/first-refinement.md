# Your first refinement

Start with an included example so you can focus on the workflow rather than preparing files.

## Open an example

Launch the [web app](https://enhantica.github.io/edi/webapp/), go to **Project**, and choose an example. The project brings its structures, experiments and analysis settings together.

## Explore the pattern

Open **Experiment** to compare the measured and calculated intensities. The residual shows the difference, and the reflection marks indicate Bragg positions.

![An experiment in EasyDiffraction](../assets/edi-app.png)

## Choose what varies

On **Analysis**, inspect the free parameters. Change the variation flags deliberately: a fit changes the parameters you allow it to change.

## Run and inspect

Start the refinement. Review the pattern, residual and parameter uncertainties together rather than judging a fit by one number.

## Keep your result

Save the project. In the browser this produces a download; on the desktop you can save to a local location. Continue with [projects and files](../application/projects.md) or [reports](../application/reports.md).
