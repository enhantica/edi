# Making diffraction analysis easier

EasyDiffraction brings diffraction modelling and refinement into a clear workflow, from an interactive application to Python scripts and command-line runs.

## One product, connected interfaces

The application, library and CLI use the edi project model and the crysta diffraction engine. Each interface serves a different working style while keeping the scientific model connected.

## Open scientific software

The [edi source](https://github.com/enhantica/edi) is available on GitHub. The repository explains the source and application licensing.
