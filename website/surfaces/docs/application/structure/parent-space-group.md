## Use this group

On **Structure → Extra**, expand **Parent space group**. A magnetic structure always has one: the space group the
magnetic group comes from, its IT number and the transform to it, read only. A file that names no parent gets the
magnetic group's own space group.

See [Magnetic structures](../../physics/magnetic.md) for the model.
