Co's and O's; La's, Ba's and Si's stay fixed, as the case's project keeps them.

Choose **lbco** in the datablock filter, then filter the **Atomic displacement** parameters using the category filter, click the **Free** column header and choose **Free · all**; then type **[Ba]** in the name filter and choose **Fixed · all** in the same menu; then type **[La]** in the name filter and choose **Fixed · all** in the same menu, then press **Fit** in the status bar.
