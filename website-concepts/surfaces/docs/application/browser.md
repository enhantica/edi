# Work in your browser

The web app is a quick way to explore EasyDiffraction without installing the application.

<p><a class="ed-button ed-button-primary" href="https://enhantica.github.io/edi/webapp/">Launch the web app ↗</a></p>

## Open an example

Choose an example on the **Project** page. Examples give you a complete starting point for inspecting a structure and comparing patterns.

## Bring your own files

The browser uses its file chooser when you load data. It does not have the same direct access to your disk as the desktop application.

## Save your work

Saving a project or report produces a browser download. Keep that download if you want to continue later or move the project to another interface.

## Use the desktop instead

For workflows centred on local project folders, see [the desktop application](desktop.md). The [workspace](workspace.md) and project concepts stay familiar.
