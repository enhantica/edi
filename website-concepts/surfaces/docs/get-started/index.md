# Start with a pattern

You do not need to choose a programming language to try EasyDiffraction. Open an example in the browser, explore a pattern, and follow the same project into Python or the command line when you need to.

<div class="ed-callout"><strong>The quickest way to explore</strong><p>Open the web app and choose an example from the Project page.</p><a class="ed-button ed-button-primary" href="https://enhantica.github.io/edi/webapp/">Open the web app ↗</a></div>

## Choose your starting point

| You want to… | Start here |
| --- | --- |
| Explore a pattern visually | [Your first refinement](first-refinement.md) |
| Work in a notebook or script | [The Python library](../python/index.md) |
| Run a saved analysis in a terminal | [The command line](../cli/index.md) |
| Understand the files first | [Projects and experiments](../learn/projects.md) |

## What is shared

The application, Python library and CLI work with the same project model: structures, experiments, fitting settings and results. Learn those ideas once in [Learn](../learn/index.md).

## What is different

Each interface has its own controls. The browser also handles files through uploads and downloads, while the desktop app can work with local folders. [Compare the interfaces](interfaces.md) before choosing a working environment.
