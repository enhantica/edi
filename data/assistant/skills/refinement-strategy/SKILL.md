# Adaptive refinement of an actual Edi project

Version: 1.5.2. Use actually offered operations and the user's goal. The contract below is evidence → supported choice → assessment, not a fixed refinement recipe, family, pass count or target statistic.

Before project mutations, establish essential probe and wavelength/TOF calibration through supplied facts and read-only inspection. If missing or conflicting, show the Assistant sidebar first and publish a final question (structured when offered), then END that turn; await the answer before creation/import/setup/refinement/Save, including independent structure preparation. Native-supported format/column/sigma handling is not a reason for extra confirmation unless loading fails or interpretation is genuinely ambiguous.

**Evidence.** Once model/data exist, establish the dominant CURRENT mismatch. Use inspect_data for actual peak-containing measured/calculated/residual regions to assess positions/shape, and off-peak regions for baseline across the range; use separate Bragg rows or SC F-squared/intensity dependence where relevant. Off-peak windows anywhere in the range establish baseline only, not peak alignment/shape. Check units, weighting, exclusions and current/adopted calculation availability. Parameter lists, convergence, low objective, absent errors and unavailable diagnostics are not residual/physical evidence. Read sufficient native slices, including full data when needed, without a fixed quota or repeated full returns merely because a fit ran.

**Choice.** Link the next supported group/model to that evidence. Resolve observed displacement with eligible cell/offset/scale alignment and supplied wavelength anchored before widths/ADPs absorb it; assess baseline bias before interpreting ADPs. Estimate alone is not baseline validation. Compare restorable changes of the implicated factor. If uncertainties leave site-specific values undetermined, assess a physically justified simpler candidate OR explicitly report the limitation; repeated parameter reads add no information. No particular equality, background release or extra fit is mandatory.

**Assessment.** Inspect adoption, actual changes, CURRENT residuals, physical widths and uncertainties before another fit consumes Undo. Stall/no_step/rejection calls for fresh model/residual/eligibility/anchor diagnosis, not unrelated ADPs. Continue justified work or report the specific incomplete assessment/unidentified quantities. Convergence, positive ADPs, no errors or lower objective alone is not adequate structural refinement; large reduced chi-square calls for data/error/model diagnosis, not forcing it to one. Successful Save/Report can preserve useful but scientifically limited work.

Preserve provenance, comparable objectives/observations, composition, symmetry, genuine calibration and requested flags. Native defaults including zero are starts; an initial free flag is not a user constraint. For a new CW task with a credible model needing alignment, try the eligible joint alignment group before another offset start. Only observed stall/rejection justifies a data-supported alternative start; never import specimen/tutorial/online fitted seeds or broaden displacement as alignment correction. Use current native conventions, units, settings and profile-reset facts.

Import a supplied CIF unless manual entry is requested. Ordinary initial Estimate uses saved type/mode/settings unless explicit manual anchors are supplied; inspect anchors/terms/eligibility without imposing anchors or changing ownership. Revisit eligible background when residuals implicate it, not as a universal all-free first stage. Settle native calculation and reconcile failed setup/free prerequisites before fitting.

Use exact paths and one whole eligible-group request when justified, with the ordinary category selector/Free header when shown membership matches, rather than checkbox loops. Credible models may support cumulative release; coordinate/ADP isolation may need joint reassessment. Revisit temporary freezes and earlier unstable but now identifiable groups: negative-ADP Undo neither finishes the problem nor restores prior flags. Obey native fittability; alternative starts/families need supported operations/restorable state. Large SU is not measured correlation; unexposed correlations remain unknown.

Check actual total components over measured reflections/range, including high angles: native CW Lorentz FWHM is X tan(theta) + Y/cos(theta), using native Bragg theta, not offset-shifted observed angle. X/Y are not universally exclusive; signed coefficients alone are not invalidity, and positive Gaussian width does not certify Lorentz width. Unknown geometry/checks stay unknown. Restore an unacceptable adopted candidate with genuine latest-fit Undo BEFORE another fit consumes it; Undo is not a checkpoint bank and refused/unadopted trials do not authorize undoing earlier science. Fixing a flag retains its current value. For diagnosis avoid changing profile family plus unrelated baseline/structure at once. Never replay partial/uncertain effects, bypass ownership, change action mode or replace scientific inputs to lower the objective.

For single-crystal data, inspect actual F-squared residuals and their intensity dependence when assessing scientifically appropriate extinction and displacement variables. Use the current native extinction family, mosaic-distribution options and exposed parameters; obey fittable/fit_reason rather than blindly applying a powder cell/wavelength release group to inactive SC fields. Enter a supplied crystal size/radius in the native field and units as requested, without inventing a diameter conversion. Model and variable choices follow evidence, not a reference screenshot. Zero local sensitivity can depend on the selected model and its other values; do not assume a zero-start stall is limited to the mixed Becker–Coppens family. Only after observing actual stall/sensitivity evidence may a supported variable receive a small positive, physically justified trial start. Explain its scale, inspect the response and uncertainty, and retain a restorable state. A zero value alone does not justify changing it; never seed fitted values from another experiment.

For mixed sites, establish the same-phase co-occupancy model/scope before relationships or shared coordinates. If separate isotropic ADPs at one mixed-species site are weakly identified, sharing is a candidate ONLY with physical justification and an explicit modelling assumption; same position/symmetry alone does not require equality. Otherwise report the undetermined values. Distinct sites of the same atom type in similar bonding environments can also support a restorable isotropic-sharing trial for weak identifiability/actual correlations; co-location is unnecessary and element alone insufficient. If data cannot resolve site-specific ADPs, consider justified broader groups/overall isotropic ADP, stating choice/unavailable comparison and lost information. One failed independent trial does not settle alternatives; negative ADPs alone do not mandate sharing or replacing established anisotropy. Match Biso/Uiso units/conversion. Native symmetry differs from modelling constraints; keep coordinates/occupancies independent and compare residuals, uncertainties and complexity. Do not equate arbitrary anisotropic tensors across frames. Supported affine constraints are not geometric restraints. No universal X-ray atom-order heuristic applies to neutrons; report correlations/conditional uncertainties honestly.

When existing guidance or a supported route fails, use hosted public search/read to discover alternatives. Relevant sources include Edi documentation and public source, engine/API documentation and scientific primary literature. Keep queries to public concepts; do not send raw experimental data, unpublished sample descriptions, credentials or private paths. Retain actual URLs/citations and explain which decisions are inferred from them. Research can identify a missing capability without pretending that Edi executed it.

At the endpoint, inspect authoritative values/SUs and current residual evidence AFTER ordinary requested/delegated Save, comparing accepted pre-Save values: Save may round/adopt/recalculate. A run_fit statistic remains pre-Save/pre-edit unless an offered metric explicitly belongs to the post-Save model. Parameter/SU reads, calculation-current/no-error flags and unquantified residual inspection do not verify chi-square/Rwp or objective equality. Assess the saved state from its actual evidence without relabelling the old trial statistic. Do not invent metric APIs, degrees of freedom, silent refits or mandatory reopen. Disclose observed material change/undetermined values while preserving genuine commit/path facts. Ordinary Save is allowed for an explicitly incomplete project; it is not scientific validation.

Quote native file_value/file_su verbatim as value ± SU with units; never reconstruct parenthetic digits/precision. If unavailable, give actual numerical SU or state absence, never zero. Distinguish observations, assumptions and unknown checks; ask only genuinely missing information/indispensable user action. Automatic work reports preserve history/research but cannot veto science. Include useful skill/tool/app recommendations without requiring /work-report.

Useful starting references for discovery, to read where relevant:

- McCusker et al., Rietveld refinement guidelines: https://journals.iucr.org/j/issues/1999/01/00/gl0561/
- Toby, International Tables for Crystallography H, Rietveld refinement (2019), model simplification and isotropic displacement grouping: https://onlinelibrary.wiley.com/iucr/itc/Ha/ch4o7v0001/
- Young (ed.), The Rietveld Method: https://doi.org/10.1093/oso/9780198555773.001.0001

References inform a strategy; they do not replace the actual user's data, native model or explicit scope.
