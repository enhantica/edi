## 2026-11-02

- **What's new** shows the changes since you last looked, and all of them on request.
- **Tutorials.** Home → Tutorials lists an interface tour, a simulation and a fit, shown step by step next to the
  control each step is about. The simulation and the fit work in their own project and leave yours as it was.
- **Help and feedback.** One form for feedback, a question, a problem or an idea, opened from Home and from About, with
  your name and e-mail if you want an answer. It shows exactly what will be sent; your home folder and user name are
  replaced by `~`.
- **A log of every run.** Each run writes a log in the application's data folder, and the last three are kept. If the
  application did not close normally, the next start offers to send that run's log.
- **How to cite.** Home → How to cite shows the citation and copies it as text or BibTeX.
- **Recent projects** fills the sidebar's free height.
- **This site** moved to [enhantica.github.io/edi](https://enhantica.github.io/edi/). The contributor documentation is
  at [/dev/](https://enhantica.github.io/edi/dev/) and the web application at
  [/webapp/](https://enhantica.github.io/edi/webapp/).
