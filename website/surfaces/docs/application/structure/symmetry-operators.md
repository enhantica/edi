## Use this group

On **Structure → Extra**, expand **Symmetry operators**. It lists the space group's symmetry operators, in the order a symmetry code refers to them. This group is read-only. See [Symmetry operators](../../physics/parameters.md#space-group-symop) in the parameter reference.
