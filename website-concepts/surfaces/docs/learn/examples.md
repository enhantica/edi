# Start from an example

Included projects give you structures, measured patterns and starting conditions together. They are useful starting points for learning the workflow.

## In the application

Open the [web app](https://enhantica.github.io/edi/webapp/) and choose **Project → Examples**. Follow [your first refinement](../get-started/first-refinement.md) to explore one.

## From Python

Load the example's project directory with `edi.Project.load(...)`, then run its declared analysis. See [load and fit a project](../python/fit.md).

## From the command line

Pass the example's directory to `python -m edi fit`. See [run a refinement](../cli/fit.md).

## Understand the inputs

Read the example's provenance and starting conditions before interpreting its result. A successful execution is useful evidence about that example; scientific agreement depends on the reference and comparison it declares.
