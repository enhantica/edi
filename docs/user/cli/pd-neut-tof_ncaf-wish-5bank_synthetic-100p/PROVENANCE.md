# Provenance

The series was made by crysta's `tools/datagen/build_seeded_series.py` from edi's
`pd-neut-tof_ncaf-wish-5bank_start-fullprof` project with `--points 100` and the defaults otherwise: point k is the
project calculated with the cell multiplied by 1 + 2·10⁻⁵ k and bank b's scale by 1 + 0.002 k (b + 1)/5, with noise
of the measured uncertainties from the seed 20261115. Only the project's name and description were changed after.
