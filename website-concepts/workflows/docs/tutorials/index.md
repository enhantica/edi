# Learn with a complete example

<p class="ed-doc-lead">Work through the same project in the application, Python or the command line.</p>

## Start with one pattern

[A powder refinement](powder.md) follows the LBCO HRPT project through the structure, experiment, fit and report. It is a useful introduction to how a complete edi project fits together.

## Continue with a scan

[Working with a scan](scan.md) introduces the difference between sequential and independent refinement. Use the same model to follow how its parameters evolve across a sequence of measured patterns.

## Find the underlying files

The current [example catalogue](https://enhantica.github.io/edi/user/cli/) records the project files behind the app's Examples. The project's model and data are shared; instructions explain the interface-specific steps.
