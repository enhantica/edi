# <span class="ed-reference-icon" data-reference-category="reflns" aria-hidden="true">&#61616;</span> Observed reflections

## Use this group

On **Experiment → Extra**, expand **Observed reflections**. For a single-crystal experiment, it sets which reflections count as observed, for its counts and R factors. See [Observed reflections](../../physics/parameters.md#reflns) in the parameter reference.
