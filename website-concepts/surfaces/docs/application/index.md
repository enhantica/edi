# The application

Explore structures, experiments and refinements in a visual workspace. EasyDiffraction is available in the browser and as a desktop application, with the same project model underneath.

![EasyDiffraction with a diffraction pattern and experiment controls](../assets/edi-app.png)

## Try it in your browser

Open the [web app](https://enhantica.github.io/edi/webapp/) and load an included example. There is nothing to install to explore it.

## Learn the workspace

The workspace follows your analysis: **Project → Structure → Experiment → Analysis → Report**. [Take a tour](workspace.md), or follow [your first refinement](../get-started/first-refinement.md).

## Choose where to work

- [Browser](browser.md): upload files and download your saved work.
- [Desktop](desktop.md): work with local project folders.

The [project concepts](../learn/projects.md) are shared with Python and the CLI.
