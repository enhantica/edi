# Use the desktop application

<p class="ed-doc-lead">Work with local projects, measured data, and the same visual analysis workflow as the browser application.</p>

## Choose a build

The current edi desktop application supports Linux on x86-64 and macOS 14 or later on Apple silicon. The new edi release and packaging information belongs here once a distributable release is available; the old EasyDiffraction download is a different generation of the application.

For this design preview, [try the current browser application](https://enhantica.github.io/edi/webapp/) or consult the [edi repository](https://github.com/enhantica/edi) for source-build information.

## Open a project

Open an existing project or start with an example. On the desktop you can use native file and folder dialogs; saving writes the project to the location you choose.

## Follow the same workflow

The Structure, Experiment, Analysis and Report pages have the same purpose in the desktop and browser application. Read [your first project](first-project.md) to explore one complete example.
